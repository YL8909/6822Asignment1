## Task 3 Prototype

This repository contains a lightweight RegTech prototype for a jurisdiction-aware AI credit scoring governance tool.

This Task 3 submission follows **Option A: Working Prototype**.

## Option A Requirement Mapping

| Option A requirement | Where it is addressed |
| --- | --- |
| Jurisdiction configuration layer | `Task3_demo.ipynb`, through the `RULES` dictionary for US and EU configurations |
| At least one live or simulated data input | `synthetic_loan_data.csv`, generated by the notebook |
| Output that means something different depending on jurisdiction | `jurisdiction_compliance_report.csv`, showing different US and EU governance outcomes |
| Model card or governance documentation stub | `model_card_governance_stub.md` |

The prototype demonstrates:

- Synthetic loan data generation
- Simple credit scoring model training
- Model performance evaluation using accuracy, AUC, and confusion matrix
- Fairness monitoring using approval disparity, false positive rate gap, and false negative rate gap
- Explainability using feature importance and rejection reasons
- Model drift monitoring over a simulated monitoring period
- A jurisdiction rule engine comparing United States and European Union compliance outcomes
- Exported tables and charts for presentation use

## Main Files

- `Task3_demo.ipynb`: Main notebook for the Task 3 prototype
- `synthetic_loan_data.csv`: Generated synthetic loan dataset
- `monitoring_results.csv`: Model monitoring and drift results
- `jurisdiction_compliance_report.csv`: US/EU compliance comparison report
- `model_card_governance_stub.md`: Model card and governance documentation stub required for Option A

## Regulatory Focus

The prototype uses real regulatory concepts from United States fair lending requirements, including ECOA, Regulation B, and CFPB guidance on adverse action explanations, and European Union high-risk AI governance requirements under Regulation (EU) 2024/1689, the EU AI Act.

The numeric thresholds in the prototype are internal governance thresholds used for demonstration. They are not statutory thresholds and should not be read as final legal interpretations.
